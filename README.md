# Growth & Conflict — Unit 2 Flipbook (showpiece edition)
Promise & Practice · a page-turning digital textbook of Unit 2 (1789–1877), all ten chapters, fully illustrated.
Self-contained: page-flip engine (StPageFlip, MIT) inlined; no CDN, no accounts, offline on Chromebooks.

## For readers
- **Laptop/Chromebook:** two-page spread. **Phone:** single page (auto); rotates cleanly.
- **Turn:** drag a page corner, ← / → , or Prev/Next.
- **Contents menu** (3 tabs): **Chapters** jump list · **Figures** — a thumbnail gallery of every image (click to jump + open it full-screen) · **Bookmarks**.
- **Search** the whole book — counts matches, jumps, highlights, ‹ › to cycle.
- **☆ Bookmark** any page; **Listen** reads the current page aloud (accessibility); **Copy link to this page** for sharing.
- Tap a **vocabulary term** to search where it appears.
- **Zoom any image** (click it) or the **page** (A− / A+ / Fit, double-click, Ctrl+scroll, +/−/0).
- **Resumes** where you left off (per device) and supports "start at page N" links (`…/#p140`).

## Craft
- Real book text; **"Be the Historian"** inquiries as boxed features; per-chapter vocabulary + a "Coming next" bridge.
- Composite cover with gentle motion; every chapter illustrated with credited public-domain images; graphic Ch 8 photos behind a Hard History opt-in reveal.
